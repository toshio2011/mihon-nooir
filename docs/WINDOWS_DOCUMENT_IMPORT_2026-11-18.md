# Windows document import — 18 Nov 2026

Stacked Windows-only draft; no Android or firmware changes. PDFBox 3.0.8 standalone Apache-distributed JAR pinned to the published SHA-512 (https://downloads.apache.org/pdfbox/3.0.8/pdfbox-app-3.0.8.jar.sha512, independently matching https://archive.apache.org/dist/pdfbox/3.0.8/pdfbox-app-3.0.8.jar.sha512). Jar includes upstream license/notice; redistribution/license review remains before public delivery. PDF original-page rendering streams images through existing five shared output writers, preserves blank/vector pages, refuses encrypted PDFs and has no arbitrary PDF source page limit (XTC native 65,535 and shared EPUB manifest limits still apply). Optional EPUB text companion includes extracted selectable text after the original page image, not Android's layout-aware mixed mode or OCR. Cancellation between PDF pages leaves no final output. Complex PDF rendering/font/interoperability and physical Windows acceptance pending. Image EPUB adapter only: reads OPF/spine ordered local raster images; rejects protected, text-bearing, external and unsupported vector-only resources rather than dropping prose. Existing 5,000-image desktop safety limit applies to image EPUB; uses staging directory; cancellation before conversion, not within existing CLI codec. No general EPUB HTML/CSS layout engine or DRM bypass. Tests create original synthetic PDFs/EPUBs, cover all formats, selectable companion, 1001 pages, cancellation, spine order/prose refusal. New CI not yet verified. Documents currently convert in their own explicit GUI workflow, not the durable manga queue.
