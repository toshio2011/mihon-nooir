## APK provenance / installation safety

The normal [Build Mihon Nooir debug APK](../../.github/workflows/build-apk.yml) CI job produces downloadable **GitHub Actions artifacts**, not an installable *official* update. It verifies build identity, files and APK signing, but **does not promise the persistent signing certificate used for official v1.0.16**.

Do **not** install a CI-signed APK over official v1.0.16 expecting an in-place upgrade. Android rejects different signing certificates for the same package ID. Avoid uninstalling an existing installation unless you have a verified and restorable backup, and preferably test on a separate device/profile. A public signed v1.0.17 release requires its own explicitly approved signing and release workflow; **this branch must not publish a release**.

Candidate PR CI must pass: Python contracts, Kotlin host tests, source-overlay integration, EPUBCheck 5.4.0, full Android FOSS assembly, app identity/signature inspection and emulator panel diagnostic smoke. Identify the **exact commit SHA** of the downloaded CI artifact before testing.

## Physical/manual acceptance: compare v1.0.16 and the candidate

Use material you are entitled to convert. Do not upload or commit copyrighted manga pages or private diagnostic ZIPs to a public repository. For any comparison, record the chapter/page number, selected settings, number of exported frames and the on-device observation.

| Test | Selected mode | Expected outcome |
| --- | --- | --- |
| Ordinary 2×3 grids | Panel by Panel + Auto Fit | Top-to-bottom, right-to-left panels, each screen as large as possible |
| Wide, tall, uneven panels | Panel by Panel + Auto Fit | Existing safe cuts, **then** orientation chosen independently for each final piece |
| White or pale-gray horizontal gap | Row by Row | Separate meaningful horizontal tiers, not individual columns |
| Mixed clear and unclear rows | Row by Row | Preserve confidently found rows; keep each uncertain region grouped |
| Dark horizontal line or crossing balloon | Row by Row | Reject speculative cuts; keep all artwork, even if result stays full-page |
| Slanted pale gap between two illustrated panels | Panel by Panel | Two **overlapping rectangular** views when confidently separated |
| Dark diagonal / touching / borderless art | Panel by Panel | Conservative grouped fallback, no missing speech or clipped edges |
| Comics with speech bubbles crossing frame edges | Both modes | Overlap or intact grouped fallback; no missing pixels or dialogue |
| Long scrolling strip | All layouts | Prior WEBTOON behavior remains for modes that permit it; Row by Row never unexpectedly uses non-row slicers |
| Full Page Before Splits | Both modes | Portrait overview only when multiple frames follow, with no duplicates |
| XTC, XTCH, EPUB2, EPUB3, CBZ | Panel by Panel | Readable correct format with frame count/order, no unexpected crop |
| X4 physical XTC/XTCH | Both modes | Correct 480×800 on-disk framebuffer dimensions; landscape views rotated into it correctly |

For each output: inspect the first/middle/last page; speech balloons at split boundaries; RTL reading order; repeated overlap; aspect ratio; file page count and cover; exit/reopen and navigation on Folio Nooir. Flag cases where landscape makes art smaller, the split produces many blank border-only screens, panels are wrongly reordered, or image is cropped.
