# MangaNooir v1.0.12 — Experimental Preview

> **Experimental Android prerelease — not a stable/device-validated release.** Automated Android build, host-side format tests and EPUBCheck passed. Real-world Android and XTEink X3/X4 compatibility testing is still in progress.

This release publishes the **unchanged APKs from successful [CI run #39734517368](https://github.com/toshio2011/mihon-nooir/actions/runs/39734517368)** (22 October 2026), built from merged commit [`5563d133`](https://github.com/toshio2011/mihon-nooir/commit/5563d13336527c64b8f248066feabcc2f7e07278) ([PR #22](https://github.com/toshio2011/mihon-nooir/pull/22)). These APKs were **not rebuilt or re-signed** for this release.

## What's new in v1.0.12

- **Five export formats:** EPUB 2.0.1 Classic, EPUB 3 Modern, XTC 1-bit Fast, XTCH 2-bit High Quality and CBZ. Improved native chapter/cover indexing, portable XTC/XTCH layout, and validated EPUB packaging.
- **Reader profiles:** XTEink X3/X4/X4 Pro and selected other e-readers, plus custom resolutions. Wi-Fi sending is only enabled for supported XTEink receivers.
- **Manga chapter selection and export queue:** choose chapters, review missing content and destination conflicts, follow background progress, and handle individual job failures without unnecessarily blocking later jobs.
- **Improved cover handling:** prefer custom/cached covers, try the source image and refresh stale source cover details when possible before showing a missing-cover warning.
- **PDF and web tools:** PDF → EPUB (real extractable text plus illustrations where possible, with scan fallback), PDF → XTC/XTCH image-based conversion, public webpage/article and web-novel EPUB tools, and Nooir Tools queue/device browser.
- **Conversion controls:** portrait/landscape, reading direction, page slicing/overlap, trimming, grayscale/dithering and compatible reader presets.
- **Interop tests:** synthetic EPUB 2/3, XTC/XTCH and CBZ fixtures; EPUBCheck 5.4.0 passes for the generated sample EPUBs.

## Known limitations

- **Not yet fully tested on physical Android/XTEink devices.** A green CI build does not guarantee every source, book or receiver works correctly. Please report failed covers, blank pages, chapter-order issues, incorrect grayscale, PDF layout problems or failed Wi-Fi uploads.
- **Signing / updating:** these are experimental CI-built APKs, not a persistent stable-key release. Their signing certificate may differ from earlier preview builds, and Android may reject an in-place update. **Back up MangaNooir library/settings before uninstalling any previous build.** The app has a separate package identity from ordinary Mihon.
- PDF semantic reflow and diagram placement are best effort; scanned PDFs have no searchable text without OCR. Some JavaScript-heavy, login-only or restricted websites cannot be extracted. No DRM/paywall bypass is provided.
- Automatic cover refresh depends on the manga source and network access; not all covers can be recovered.
- Some device-specific behavior, high-volume jobs and advanced web-to-reader formats remain experimental. **Windows desktop `.exe` is planned, not included.**
- The app bundles no manga, source extensions or catalog. MangaNooir is unofficial and not affiliated with Mihon, XTEink or third-party firmware projects.

## Download and install

For most modern Android phones, download **`app-arm64-v8a-foss.apk`**. If unsure which ABI your device uses, choose **`app-universal-foss.apk`**. Download the APK directly from this release's Assets section and install using Android's file manager.

If Android reports an incompatible existing installation, **back up the existing MangaNooir data first**. Do not uninstall ordinary Mihon to install MangaNooir.
