# MihonNooir v1.0.20 — Universal Book Converter & Web → EPUB

**Android release candidate.** Publication is contingent on persistent-key signing and the in-place upgrade check. This document is a proposed public release note, not evidence of publication.

## What's new

- **Universal Book Converter** in More → Nooir Tools. Pick your input file type (EPUB, manga CBZ/ZIP or supported images), choose applicable output and its settings, then save on Android or transfer to a supported XTEink reader. Existing manga exports and the separate PDF tool remain available.
- **EPUB → XTC / XTCH** with selectable supported typography, spacing and reading direction, images and actual-output previews. Inspect saved XTC/XTCH pages directly through the Android file picker.
- **Web → EPUB** for public articles and novels: discover/select chapters, combine into one book or export a story, adjust book title/author/description/language, EPUB2/EPUB3 and image/reading options, and choose or auto-detect a public JPEG/PNG cover.
- **Wattpad story metadata**: for publicly exposed stories, carry the story-level cover, title, author and synopsis into the book, including a **Synopsis** TOC page after the cover and a `dc:description` metadata field, rather than relying on the first chapter's webpage metadata.
- **No regressions intended** to v1.0.19 manga panel detection, PDF conversion, rendering modes, Context Peek, queue, reader transfer, or architecture-aware updater.

## Known limitations

- Only publicly returned site content is read. The app does not bypass login requirements, website restrictions, paid chapters, rate limits or paywalls and does not collect browser-session cookies. Chapters advertised by public metadata may still be unreadable from Android.
- Automatic covers and descriptions depend on public website metadata; choose your own supported cover in Nooir Tools when needed. One user-tested Wattpad story is not universal compatibility evidence.
- Complex CSS EPUBs, long web novels, giant illustrated books, different Android devices and actual Wi-Fi reader compatibility continue to need user testing. Windows and Folio Nooir firmware are unaffected.

- **v1.0.20 must additionally pass signed release QA:** five FOSS architectures signed with the existing official persistent key, all APK manifests reporting package `dev.nooir.mihontrial.foss`, `versionCode=1000020`, `versionName=1.0.20`, no debug certificate/privileged installer permissions, checksum validation, certificate equality with official v1.0.19 and Android 16 emulator in-place upgrade v1.0.19 → v1.0.20 preserving the app UID. Debug-signed CI APKs are NOT official updates.
- Back up your existing library and important downloads before upgrading. Install the correctly matched architecture APK over official v1.0.19; do not uninstall or clear data if Android reports a signature/package conflict. Most modern phones use ARM64; choose universal if unsure.
- Promote only the **exact previously verified signed candidate assets** and checksums to a public v1.0.20 release. Never rebuild, substitute or auto-publish unverified artifacts.
