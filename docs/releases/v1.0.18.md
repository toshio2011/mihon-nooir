# MihonNooir v1.0.18 — Android updater maintenance

**Release status:** development candidate only. **Do not publish or call stable** until the emulator in-place upgrade and a real Android-device upgrade are verified.

This release is deliberately focused on updating MihonNooir safely. It **does not change** panel extraction, the Windows desktop application, or Folio Nooir firmware.

## What's fixed

- In-app updates now select the **exact APK matching your device's supported architecture**. The previous inherited Mihon selector accidentally treated every `-foss.apk` asset as the same build and could choose the last GitHub asset (x86_64) even for an ARM64 phone.
- The selector does not depend on GitHub asset ordering. It tries supported ABIs in Android's priority order, then the official universal APK. It does not silently choose an incompatible binary or treat checksums as APKs.
- The update action sends you to the official APK in a browser, with instructions to install **over the current app** using Android's normal confirmation. It does not request unrestricted package installation permissions or uninstall your existing app.

## Important for users already on v1.0.17

**The in-app updater in the already-installed v1.0.17 still has the original wrong-architecture bug.** Your first update to v1.0.18 may therefore require downloading the correct official APK directly from this release's assets when/if it is published. For ARM64 devices (including the user's REDMAGIC 9 Pro), choose `app-arm64-v8a-foss.apk`. After installing v1.0.18, future updates should use the corrected APK selection.

**Do not uninstall v1.0.17 just to update.** Make a normal MihonNooir backup before upgrading and keep your library/source data intact. Android may require approval to install an APK from your chosen browser or Downloads app.
