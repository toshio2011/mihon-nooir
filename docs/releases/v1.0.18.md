# MihonNooir v1.0.18 — Android candidate

**Status: isolated, unmerged release candidate. NOT published.**

This candidate combines reviewed Android work from draft PDF PR #82, Android visual PR #83, shared/Windows integration PR #85, and updater maintenance draft PR #80. The Android update includes PDF and manga conversion improvements, four selectable monochrome rendering modes with explanations, opt-in Context Peek for detected manga panels, an actual saved-XTC/XTCH preview separate from the pre-export live preview, and safer output cancellation. Windows remains a **separate unsigned developer preview** and is **not part of the Android APK**.

## Android v1.0.18 functionality
- Preserve existing Android manga reader, live preview, download/library flows and saved local data.
- Inspect real finished XTC/XTCH books through Android's document picker, with guarded decoder and temporary-file cancellation cleanup.
- Choose original Floyd–Steinberg, Atkinson, Bayer 8×8 or Threshold rendering. Legacy export settings keep their previous behavior; opt-in panel Context Peek defaults OFF.
- Longer PDF-to-EPUB2/3 and PDF-to-XTC/XTCH conversions with no arbitrary source page cap; multi-file PDF selection handled sequentially. Upload limits apply only to actual e-reader transfers, not local phone saves. Cancellation avoids promoting incomplete output.
- In-app updater selects an architecture-compatible official APK instead of mistaking x86_64 for ARM64. Its action uses the browser/Downloads for ordinary Android user-approved installation, with no package-install permission.

## Upgrade from v1.0.17 (IMPORTANT)
- v1.0.17 may pick the wrong CPU architecture when using its *old* updater. For the **first** upgrade, download the exact new official-signed v1.0.18 `app-arm64-v8a-foss.apk` from the reviewed candidate artifact, check its SHA256, and install **over** official v1.0.17 with Android confirmation. Never uninstall, clear data or substitute an ordinary debug-signed Actions APK.
- The side-by-side `MihonNooir QA` build is a different Android package used only for separate testing. It does not migrate the official app library or replace the signed candidate.
- Back up the installed official app's library and important downloaded books before the first in-place upgrade.
