# MihonNooir v1.0.18 — Android

This Android release brings the tested manga/PDF export refinements, real saved-book preview, four monochrome rendering choices and a safer in-app update path. It builds on MihonNooir v1.0.17 and uses the same official application ID and persistent Android signing certificate.

## New and improved

- **Actual XTC/XTCH previews:** inspect the real encoded bytes of a finished book, separately from the existing pre-export live manga preview. A bad or incomplete file is rejected instead of displayed as a valid book.
- **Four rendering methods:** Floyd–Steinberg (default), Atkinson, Bayer 8×8 and Threshold, with setting descriptions on Android and corresponding visual test fixtures. Existing export settings retain their original default behavior.
- **Manga panel handling:** refinement of panel detection and protected page slicing, including short ruled footers, preserving sparse panels and optional **Context Peek** (off by default). The original live manga preview remains available.
- **Long PDF/multiple inputs:** PDF-to-EPUB2/3 and PDF-to-XTC/XTCH paths tested beyond 1,000 and 2,000 source pages; sequential PDF selection, selectable text where supported, mixed text/illustrations and cancellable local saving. There is no arbitrary local source-page cap; e-reader transfer size is a separate limit.
- **Updater fix:** pick an exact compatible APK for your Android CPU architecture rather than treating all GitHub FOSS APK assets as interchangeable. The update action opens the official download in your browser so Android's normal installer can ask for approval.

## How to update from official v1.0.17

**Back up your current MihonNooir library and any important downloaded chapters first.** Use the APKs attached to **this GitHub v1.0.18 release**, not APKs from PR/debug workflows or the separate "MihonNooir QA" installation.

The **old v1.0.17 in-app updater** can select an incompatible CPU architecture. For this first upgrade, download the correct release APK manually. On an ARM64 Android phone, choose `app-arm64-v8a-foss.apk` (or the official universal FOSS APK if appropriate); verify the file against `SHA256SUMS.txt`. Install **over your existing MihonNooir** using Android's normal confirmation. **Do not uninstall, clear storage or change package IDs.** If Android reports a package/signature conflict, stop and report it.

After updating, confirm About displays **FOSS v1.0.18**, and check your library, reading position and downloaded chapters.

## Verification

- The production-key-signed Android v1.0.18 candidate passed signature matching against public v1.0.17 for all five ABI APKs and Android 16 in-place emulator upgrade with unchanged package UID: [signed release-candidate tests](https://github.com/toshio2011/mihon-nooir/actions/runs/43838554182).
- All 3 Android panel/saved-book-preview emulator tests and all 7 long-PDF emulator tests passed together on the integrated candidate: [Android integration tests](https://github.com/toshio2011/mihon-nooir/actions/runs/43838633554).
- The owner confirmed a successful in-place v1.0.17 → v1.0.18 upgrade on a physical Android phone, with existing library, downloads and reading progress retained, and reported that scanning worked. This is a first-device acceptance observation, not a guarantee across every device.
- The public release workflow independently revalidates the five signed APKs, the v1.0.17 signing identity, Android 16 upgrade compatibility and bundled SHA-256 checksums before publishing.

## Scope

**Android APKs only.** Windows remains a separate unsigned development preview; no Windows installer or Folio Nooir firmware is included in this release. The standalone Windows-only draft pull requests remain separate.
