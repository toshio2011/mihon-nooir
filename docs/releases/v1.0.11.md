# MangaNooir v1.0.11 — Experimental Preview

> **Experimental Android build, not a stable release.** The Android compile and format/unit smoke tests passed, but real-device and cross-firmware tests are incomplete.

Built from **commit `343fb29c04c7053c50741d5c844cf7e564f7c996`** on the MangaNooir experimental branch. [Verified CI run](https://github.com/toshio2011/mihon-nooir/actions/runs/39375003996) (20 October 2026). This pre-release publishes the **same CI-built APKs**, not a recompiled or modified application.

## What's included

- Full Mihon-based manga reading, library and chapter selection.
- Select chapters and export XTC (black-and-white), XTCH (4 grayscale levels), EPUB and CBZ for XTEink or other compatible readers. Portrait/landscape, right-to-left, page overlap, contrast, dithering and trimming options are available.
- Use Mihon's available series cover as the first exported manga page, preserve native book metadata and supported chapter navigation.
- **PDF → EPUB:** Attempt reflow of selectable text with inline figures; scanned or complex pages use image fallback, without OCR.
- **Web → EPUB:** Public article conversion, multiple links combined into one EPUB, and supported public web-novel batch conversion.
- **Wi-Fi file transfer:** Send to an XTEink device, browse compatible files, track progress in the Nooir Activity Queue, handle duplicate destination names and ordinary per-book failures.

## Known limitations / before testing

- Some web sources require JavaScript, authentication or an unsupported chapter structure; no login/paywall/DRM bypass. PDF layout and scanned-page quality vary; no OCR.
- High-volume conversion, transfer and third-party firmware behavior still require broader testing. XTC/XTCH page-zero cover export is included; compatible reader firmware handles its own thumbnail cache.
- **Signing:** these are CI-signed experimental APKs, not stable-key-signed builds. Different CI runs may have different signing certificates; Android may refuse an in-place update. **Back up MangaNooir before uninstalling** or replacing test builds.
- MangaNooir is unofficial. It bundles no manga, extensions or catalog.

## Download and install

For most current Android phones choose **`app-arm64-v8a-foss.apk`**. If unsure about your CPU type choose **`app-universal-foss.apk`**. Other ABI variants are also provided. Install the APK using Android's file manager. MangaNooir has its own package identity, separate from ordinary Mihon.
