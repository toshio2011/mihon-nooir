# MihonNooir v1.0.19 — Smarter Manga Reading

This Android update focuses on more natural manga panels and better readability on e-readers, rather than simply producing more splits.

## What's new
- Improved recognition of supported mixed, slanted and staggered panel layouts, including tall independent panels beside stacked panels.
- Rejoin suspicious narrow fragments and shallow headers across weak boundaries; retain genuine narrow panels with convincing borders.
- Recover missed individual panels when a grouped region contains a strongly verified internal gutter.
- Preserve supported standalone illustrations and activity artwork instead of splitting them unnecessarily.
- **Enlarge oversized splits**, enabled by default in Panel by Panel and Row by Row: adjustable minimum screen fill (25–80%, default 50%). Prefer natural boundaries, then use 12% protective overlap for eligible regions only if both views improve scale. Ordinary overlap is still independently adjustable.
- Updated conversion guides. Existing live preview, actual XTC/XTCH preview, four rendering styles, Context Peek, PDF/EPUB/CBZ conversion, transfers and architecture-aware updater remain available.

## Recommended manga settings
Panel by Panel + Auto Fit, with Enlarge oversized splits enabled at the default 50% screen fill. Preview your manga before exporting. Panel detection is heuristic: unusual artwork can still be grouped or split incorrectly. Use Row by Row or Page mode where appropriate.

## Updating
Back up your library and important downloaded chapters. From official v1.0.18, install the appropriate APK over your existing app or use the updater. From v1.0.17, manually choose the correct architecture because the older updater could select the wrong APK. ARM64 is suitable for most modern Android phones; choose Universal if unsure. Do not uninstall or clear app data to resolve an installation conflict. If a conflict occurs, stop and report it. Check SHA256SUMS.txt and confirm About displays FOSS v1.0.19.
