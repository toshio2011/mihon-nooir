# MihonNooir v1.0.19 — Android release candidate

**Draft, not published.** This candidate builds on the official v1.0.18 Android release and the latest main documentation. Windows is not included in the Android release; Folio Nooir firmware is unchanged.

## New in this candidate

- **Smarter manga splitting:** improved recognition of supported mixed, slanted row and panel layouts. Row by Row keeps full-width tiers; Panel by Panel attempts individual panels in reading order.
- **Preserve artwork:** guard against fragmenting certain enclosed activity illustrations and keep already-readable continuous illustrated regions intact. Detection is heuristic; use Page mode when a layout is not recognized.
- **Enlarge oversized splits:** enabled by default in Row by Row and Panel by Panel. Configure Minimum screen fill (25–80%, default 50%). Attempt verified natural boundaries where supported, then use 12% protective overlap for eligible hard-to-fit views only when both zoomed views improve scale. Ordinary Overlapping page cuts remains separate. Auto Fit is still available; manual orientation may produce different counts.
- **Tall spanning panels:** preserve a validated independent panel alongside stacked neighbors; consider enlarging only that region when it is poorly fitted. Existing protections and the original source images are retained.

## Upgrade (once the release is approved and published)

Back up your library and important downloaded chapters. Official v1.0.18 users should use the existing updater or download the appropriate official APK from the published v1.0.19 release. Install over the existing application; never uninstall or clear data to resolve a signature conflict. Check the official SHA256SUMS.txt, confirm About shows FOSS v1.0.19, and check your library, progress, downloads and conversion settings. For earlier APKs with different signing identity, stop rather than uninstalling.

## Evidence and remaining gates

- [PR #103](https://github.com/toshio2011/mihon-nooir/pull/103): shared detector build, Android smoke and Windows CI passed; exact desktop artifact reproduced the two owner-reviewed source layouts. Private local A/B corpus: 62 sources, 248 matched page/mode/orientation cases, 240/248 pixel-identical, eight differences on two target sources. Local prototype vs earlier desktop build, not evidence of exact Android raster parity.
- [PR #104 Android emulator](https://github.com/toshio2011/mihon-nooir/actions/runs/44415622189): all five instrumentation tests passed, including the new synthetic mixed-layout 3-row/6-panel test and actual XTC/XTCH round-trip pixel checks.
- Clean RC requires fresh APK build, all five emulator tests, long-PDF regression, five stable-key APKs and SHA-256 checksums, signer match against official v1.0.18, in-place Android 16 package upgrade with UID retained and owner's physical upgrade acceptance. No claim of verified library migration until that device check.
- Publication is separate and requires explicit approval. No debug APK is a public release asset.
