# MihonNooir v1.0.17 — Official Android Release

**Release status:** Public production update, signed with the **same persistent release certificate** as the official v1.0.16 APKs. All published APK variants must pass certificate-continuity and Android package/version verification. Do not use a debug-signed QA APK to update an official installation.

## Reader-first panel export refinements

- Existing manga Panel by Panel / Row by Row options, RTL reading order, EPUB 2/3, XTC/XTCH, CBZ, Full Page Before Splits and Auto Fit are retained.
- Improve recognition of clear and dark comic panel gutters, paired diagonal frame rails, and conservative internal column recovery after rejected cuts.
- Keep text-dominant pages and intentional full-page splash artwork intact rather than fragmenting them.
- Restore speech bubbles to their illustrated panels when a false 29–35px piece is detected; block merges across strong genuine panel borders.
- Limit useless standalone scan headers/footers, absorbing nine low-ink edge views into adjacent artwork without discarding original source pixels.
- Give oversized unsplit rows one bounded second look for trustworthy panels, followed by guarded overlapping reading views only when needed.
- Preserve two useful zoomed views after removing a nearly empty scan header (the One Piece source page 60 QA9 regression fixed in QA10).
- Preserve reading order, manual orientation, and guarded fallback coverage.

## Evidence and remaining limitations

The original private One Piece sample contains 201 source pages. User-supplied QA9 EPUB had 1,044 PNG images, no images under 1% dark-pixel coverage, and matching diagnostics confirmed nine edge absorptions and six speech/art joins. The user-supplied QA10 EPUB had 1,046 PNG images; its two added images restored useful page-60 close-ups. All 1,044 QA9 exported image signatures (dimensions, size and perceptual hash) were retained in QA10 after alignment; this is not a byte-identical comparison. **QA10 matching diagnostic ZIP and physical X4 read-through remain pending.** Some sparse credit/decorative strips and complex overlapping panel art may remain. Full visual and physical QA should continue in future versions.

This update affects the Android manga converter, not Folio Nooir firmware or Windows application. Panel Diagnostics remain an opt-in private ZIP; the source images may be copyrighted, and nothing is uploaded automatically.

## Install over official v1.0.16

1. Back up your MihonNooir library/settings before testing.
2. **Do not uninstall** your current v1.0.16 or install QA9/QA10 on top of it. QA packages are separate, temporary test apps and do not share the official signing identity.
3. The production `v1.0.17` release has **package `dev.nooir.mihontrial.foss`**, Android `versionCode=1000017`, `versionName=1.0.17`, and must match **the signing certificate of official v1.0.16**. The release workflow must stop if the signature differs.
4. For an in-place update, use only the **official v1.0.17 signed APK** that passed signer continuity verification against v1.0.16; install it over the existing official app. Android will refuse a mismatched signature instead of performing an update.
5. After publishing the official non-prerelease GitHub `v1.0.17` release with the five named FOSS APK variants and SHA256SUMS, the app's update checker should discover it via the fork's GitHub releases. An in-app update prompt depends on the existing updater settings and device permissions. Manual installation of the appropriately signed APK is an alternative.

Never publish unsigned/debug builds or commit the keystore/passwords. The signing secrets belong in repository Actions secrets. **An Actions artifact is not a GitHub Release and will not appear in the automatic update checker.**
