# MihonNooir v1.0.16 — Android Experimental Release

**Source:** `30681a3f80a2c4e4a31376603e6def60269c8ed2` (last green, user-tested Conan Panel export candidate).  
**Validated:** [Full Android FOSS and synthetic emulator diagnostic CI #40690833060](https://github.com/toshio2011/mihon-nooir/actions/runs/40690833060).  
**Release policy:** persistent keystore only; debug-signed APKs must NOT be published.
**Build environment:** uses the GitHub-hosted runner's preinstalled Android SDK (the optional SDK installer attempted an obsolete package on the first signed release run). This is an experimental Android release, not a completed Windows desktop application.

## What's new since published v1.0.12

- **Panel by Panel and Row by Row** manga exports, with Japanese manga RTL ordering, **Auto Fit**, and optional **Full Page Before Splits** overview pages.
- **Conservative panel refinement based on real Detective Conan samples:** avoid independent border-only footer fragments, improve splitting genuinely framed upper columns where safe, and avoid chopping a shallow typographic title band into multiple word fragments.
- **Private, opt-in Panel Diagnostic ZIP** for a chosen export: toggle **Save panel diagnostics after this export** in More conversion settings → Panel by Panel. It is **OFF by default** and resets off after queuing the job; no automatic upload. After successful export, use **Save latest panel diagnostics ZIP** from the export dialog. The ZIP contains thumbnails and potentially copyrighted source imagery; inspect before choosing to share.
- Maintain the existing manga reader, sources/library behavior, selected-chapter conversion/transfer, and EPUB 2, EPUB 3, XTC, XTCH and CBZ export formats.
- No change to Folio Nooir firmware. No OCR, paid AI or required manual panel-preview workflow.

## Validation and current limitations

- Successful exact-source host format tests, EPUBCheck, a full FOSS APK build, one-bit/two-bit Android emulator export parity and private diagnostic ZIP integrity.
- **Real Detective Conan export:** 67 input pages produced 325 frames including cover. The user-provided EPUB confirmed the earlier footer-only fragments were absent, the formerly grouped top illustrated panels separated, and a five-fragment title strip was preserved as a single band.
- **Known accepted limitations:** some smaller illustrated panels may remain grouped when a divider cannot be validated safely. A title-band view may still have some cut/duplicate lettering at its top edge; the newer experimental title-joining attempt was excluded because its regression test failed. Full manual review of every source/reader/device profile is not claimed.
- Row by Row and intentional Full Page Before Splits behavior should remain intact. Please report any clipped balloons, missing artwork, bad reading order, cover issues or failed transfers.
- There is **no finished Windows installer or full desktop app** in this release. Desktop work is still in development.
- The app does not bundle or distribute manga, catalog contents or third-party source extensions. Unofficial project; not endorsed by Mihon or XTEink.

## Download, install and backup

For modern 64-bit Android phones (including REDMAGIC 9 Pro), select `app-arm64-v8a-foss.apk` in the Assets list. `app-universal-foss.apk` is available when unsure which processor architecture is installed. Validate `SHA256SUMS.txt` if desired.

**Important update-signature warning:** The earlier public v1.0.12 APKs were published from an experimental CI build signed using an ephemeral debug certificate. This version uses a **persistent keystore**, so Android may refuse an in-place update from older builds with a different signing certificate. **Back up your existing MihonNooir data before uninstalling anything**. Uninstalling can remove the local library, downloads and settings. Do not remove ordinary Mihon; the fork has its own package name. Never bypass Android or Play Protect security prompts.

If installation is rejected, check the reported message and file an issue rather than turning off phone protections.

**Technical note:** This version is published from the frozen, previously green source plus release-only documentation/workflow. The newer title-band polishing commit that failed its regression test is intentionally not included.

## Feedback

Use [MihonNooir issues](https://github.com/toshio2011/mihon-nooir/issues) and [the existing roadmap issue #8](https://github.com/toshio2011/mihon-nooir/issues/8) for feedback. When submitting a diagnostic ZIP, share only in a private channel with permission to share the images.

**Release qualification:** The publication workflow checks ZIP integrity, Android package identity, version, APK signature scheme, common signing certificate and removal of privileged installer permissions. A failure stops publication and reports the specific failed check; it must not be bypassed to publish an unverified APK.

**Signing-certificate qualification:** the gate requires one SHA-256 digest from the verified APK's signer certificate and the same digest across all five architecture APKs. It rejects debug certificates; no private signing material is included in release assets.
The release CI uses the APK certificate digest for all architectures and refuses to overwrite an existing tag.
