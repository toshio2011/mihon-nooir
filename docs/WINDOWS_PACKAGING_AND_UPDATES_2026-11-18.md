# Windows packaging and update channel draft — 18 Nov 2026

Stacked after #90; Windows-only. Initial development preview version 0.1.0 is separate from Android v1.0.18. Creates versioned x64 portable ZIP and per-user MSI using the bundled Java runtime and WiX 3; records unsigned Authenticode status and bundles SHA256SUMS-windows.txt. Reuses exact native launcher gate for both portable and installed app. Disposable Windows CI must install, launch and uninstall the MSI, demonstrate separate test data sentinel is retained, and preserve prior source/GUI/backend gates. No existing installation is overwritten in CI. No signed release certificate, cross-version MSI upgrade test, installer UX on physical PC or tested public package yet. Android app signing key is not a Windows code signing certificate.

The explicit Windows updates button reads repository release metadata and only considers windows-vMAJOR.MINOR.PATCH with supported Windows assets, exact official HTTPS URLs and checksum manifest; includes prereleases only when the user selects them. Opens official release page after confirmation, does not download or execute. Public Windows release must use a separate tag and not mark itself latest over Android (preview remains prerelease). The old Android release workflow is unchanged. Initial version is a provisional developer-preview decision, not a claim of production completeness. Public release, signed installer, manual backup/restore, actual-source/reader transfer, existing-install upgrade QA remain gates.
