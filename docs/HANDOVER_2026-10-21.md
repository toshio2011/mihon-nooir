## 2. Product vision and existing v1.0.11 features

MangaNooir is a full **Mihon Android manga reader** plus an e-reader conversion/transfer companion, not an unrelated converter. Keep Mihon's library, source extensions, reading, chapter selection, downloaded/online chapters, history, tracking, backup and other normal functionality.

Existing experimental features inherited from v1.0.11 must remain: selecting chapter ranges; normal downloaded chapter export and Quick Export that fetches missing online pages chapter-by-chapter; XTC/XTCH/EPUB 3/CBZ; page orientation, white-margin crop, splitting, overlapping cuts, contrast, dither and reading direction; Nooir Tools; imported Android CBZ/images/files; PDF → mixed selectable-text-and-image reflowable EPUB (no AI/OCR); public web article → EPUB; multiple webpage URLs → one EPUB; public web novels including all discoverable chapters; XTEink HTTP transfer and file browsing; destination name preflight; and sequential WorkManager activity queue with per-book failure isolation.

Preserve document fidelity: where PDFs contain genuine text and illustrations (reference: *Strange Houses*), keep selectable prose and images together in EPUB; fall back to images for scanned/complex pages, without inventing OCR text. Some public websites will fail because they need JavaScript/authentication. Do not misrepresent these limitations.

## 3. What PR #21 already implements

### Device profiles (12 built-in presets + custom)

- **XTEink:** X3 **528×792**, X4 **480×800**, X4 Pro **480×800**.
- **Kindle:** Paperwhite 12 / 11 and Kindle 11.
- **Kobo:** Clara BW, Libra 2, Libra Colour.
- **Boox:** Palma, Page.
- **PocketBook:** Verse Pro.
- **Custom:** 64–4096 pixels per edge, with a **3,000,000-pixel** total cap. Invalid/unknown device IDs fail instead of silently becoming X4.
- Presets carry output dimensions, allowed formats, automatic format, and whether **XTEink-style Wi-Fi upload is even eligible**. X3/X4 keep legacy IDs, resolutions and XTCH Auto. Kindle defaults to EPUB 3; select Kobo/Boox/PocketBook default to CBZ. Other formats must be explicitly compatible.
- Non-XTEink device profiles export to the Android phone; they **cannot** be uploaded via Folio/CrossPoint's XTEink HTTP API. Kindle EPUB should be delivered via **Send to Kindle** where appropriate. This is not automatic delivery to other devices, nor proof their stock firmware reads every format.
- A shared `NooirDevicePicker` appears in manga and imported-file conversion UI. Previous device/format preferences are retained where possible.
- Source paths: `overlay/app/src/main/java/dev/nooir/bridge/NooirDeviceProfiles.kt`, `ExportFormats.kt`; `overlay/app/src/main/java/dev/nooir/mangabridge/NooirDevicePicker.kt`, `NooirExportDialog.kt`, `AnyFileTransferDialog.kt`, `MihonNooirExporter.kt`, `ImportedMangaConverter.kt`.

### Four distinct manga-export formats (CBZ also retained)

| Format | Writer / implementation | Cover, synopsis and navigation |
| --- | --- | --- |
| **EPUB 2 Classic** | `Epub2Writer.kt`, genuine **EPUB 2.0.1 / OPF 2.0**, NCX and simple XHTML | `meta name="cover" content="cover-image"` references a **real manifest PNG image**; XHTML cover and guide link if dedicated artwork exists; real `dc:creator` and `dc:description` only when supplied; NCX chapter navigation |
| **EPUB 3 Modern** | Existing `BookArchiveWriter.kt`, unchanged modern EPUB version | Fixed image-page EPUB 3 with nav XHTML and EPUB 3 `cover-image` when real dedicated artwork exists |
| **XTC Fast** | `XtcCodec.kt`, container `XTC\\0`, page `XTG\\0` | 1-bit, row-major MSB-first pages; Folio renders first page as cover; optional 96-byte chapter records |
| **XTCH High Quality** | `XtcCodec.kt`, container `XTCH`, page `XTH\\0` | 2-bit (four gray levels), two right-to-left column-major vertical-bit planes; first page as cover; same chapter table |

- EPUB 2 is currently selected for **manga/image/CBZ conversion**, not for web/PDF reflow exporters; the latter still produce **EPUB 3**. Don't claim global EPUB 2 conversion.
- EPUB 2 writes `mimetype` as the **first, STORED, no-extra ZIP member**, with exact MIME text; `META-INF/container.xml`, `OEBPS/package.opf`, XHTML reading pages, PNG images, `OEBPS/toc.ncx`. OPF is capped at **512 KiB** because of Folio Nooir's parser. EPUB 2 does not emit the EPUB 3-only `page-progression-direction` spine attribute.
- **Cover toggle:** `More conversion settings → Include separate series cover` (default on). For Mihon manga, use the actual series cover from custom/cache/source; it is page 0 when available and does not replace/discard chapter images. When disabled, chapter page 1 becomes page 0. Missing requested series covers produce a clear error for XTC/XTCH rather than fabricating artwork; EPUB 2 omits fake cover metadata if not provided. `MangaConversionOptions` settings token remains backwards-compatible with older values.
- **XTC/XTCH portable layout:** 56-byte extended container header; 256-byte optional metadata; 96-byte chapter entries with 1-based start/end; 16-byte absolute-offset page table; uncompressed 22-byte page headers. X4 (480×800) page bytes: **XTC 48,022**, **XTCH 96,022**. Maximum **65,535** pages in the on-disk header. Title/author are bounded UTF-8 in native metadata. Normal exports **no longer append** private `NOOIRMD1` JSON or arbitrary synopsis bytes. The core images are spooled to disk rather than buffering every page.
- **XTC synopsis:** Folio Nooir's current binary reader consumes title/author, **not** a portable synopsis field. Source synopsis remains in MangaNooir conversion metadata. Compatible direct Wi-Fi uploads may separately call Folio Nooir `POST /api/book` to set reader-side metadata; SD/USB copies cannot rely on that. Optional versioned sidecar is a **future proposal**, not implemented.
- **CBZ** remains available, with `ComicInfo.xml`.

Main source files: `overlay/app/src/main/java/dev/nooir/bridge/Epub2Writer.kt`, `BookArchiveWriter.kt`, `XtcCodec.kt`, `ExportFormats.kt`; `overlay/app/src/main/java/dev/nooir/mangabridge/MihonNooirExporter.kt`, `ImportedMangaConverter.kt`, `MangaConversionOptions.kt`.

## 4. Folio Nooir is read-only compatibility evidence

Reference **https://github.com/toshio2011/folio-nooir**. The source inspected for this task included:
`lib/Epub/Epub.cpp`, `lib/Epub/Epub/parsers/ContainerParser.cpp`, `lib/Epub/Epub/parsers/ContentOpfParser.cpp`, `lib/Xtc/Xtc/XtcTypes.h`, `lib/Xtc/Xtc/XtcParser.cpp`, `lib/Xtc/Xtc.cpp`, and `src/activities/home/RecentBooksActivity.cpp`.

Verified parser contracts: EPUB `container.xml` locates the OPF; native title/author/description extracted from OPF; traditional EPUB 2 `meta name=cover` must identify an **image**, not XHTML wrapper; NCX recognized; OPF file-size guard **512 KiB**; manual shelf-cover image source guard **3 MiB** in inspected source. For XTC/XTCH, shelf thumbnail uses **page 0**, not an assumed embedded thumbnail; 1-based on-disk chapter ranges become zero-based in memory. XTC: row-major 1-bit XTG; XTCH: two right-to-left vertical bit planes XTH.

**Important:** The user's local **Folio Nooir 1.6.6 bounded-memory XTCH thumbnail changes were not directly accessible as uncommitted local files**; do not claim to have inspected them. The user reports MangaNooir XTCH **now displays its cover correctly** on a repaired Folio Nooir device. Do not restore the obsolete “XTCH covers always fail” warning. This does **not** prove compatibility with CrossPoint/CrossInk/stock/other firmware. **Do not modify the Folio Nooir repo.**
