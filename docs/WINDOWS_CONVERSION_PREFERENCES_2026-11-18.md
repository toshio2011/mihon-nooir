This Windows-only draft stores explicitly accepted conversion settings in the existing data root, using the shared token and atomic replacement. Missing file uses Manga defaults; corrupt or inaccessible input keeps its bytes and is reported at startup; failed save leaves choices active only for this session. Safety flags (missing cover approval, skip unavailable chapters, private Android diagnostics) are not saved. Batch and image EPUB dialogs start from current defaults, but their per-job edits do not replace the defaults. Existing queue tokens are untouched. PDF settings, reader profile/format selection, server credentials, Android settings and firmware are outside this change. Fresh windows load saved data and disposable installed-runtime tests verify the preference file in fresh JVMs after synthetic MSI upgrade/uninstall/reinstall. New tests pending; not release approval. Real manga / physical Windows/reader acceptance and signing remain pending.
